# AI Revenue Recovery

Clean project scaffold for the Razorpay AI Revenue Recovery Buildathon.

## Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Java + Spring Boot + Spring Security + JWT
- Database: PostgreSQL
- AI Service: Python + FastAPI + LLM/ML
- Payment: Razorpay Test APIs + Webhooks
- Tooling: GitHub + Docker

Implementation is intentionally not included in this scaffold.
